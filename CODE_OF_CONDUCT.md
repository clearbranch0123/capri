# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in the Capri project a respectful, harassment-free experience for everyone, regardless of background, identity, or experience level.

## Expected Behavior

- Be constructive, empathetic, and respectful in issues, pull requests, and discussions.
- Focus feedback on technical quality, user experience, and safety rather than individuals.
- Respect maintainers' time and project scope (including non-commercial fan-project boundaries in [`ASSETS_NOTICE.md`](ASSETS_NOTICE.md)).

## Unacceptable Behavior

- Harassment, personal attacks, slurs, or discriminatory remarks.
- Publishing others' private information (doxxing), credentials, or secrets.
- Deliberate disruption of issue trackers, pull requests, or community spaces.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, or pull requests that violate this Code of Conduct, or ban repeat offenders from the repository. Report concerns privately via the contact channels listed in [`SECURITY.md`](SECURITY.md).
